PT 세션 타이머 개인정보처리방침

시행일: 2026년 11월 6일

요약: PT 세션 타이머(이하 ‘앱’)는 개인정보를 수집하지 않으며, 입력한 데이터를 서버나 제3자에게 전송하지 않습니다. 모든 기록은 사용자 기기 안에만 저장됩니다.

1. 수집하는 개인정보

앱은 이름, 이메일, 전화번호, 계정, 위치, 광고 ID, 기기 식별자 등 어떠한 개인정보도 수집하지 않습니다. 앱에는 회원가입·로그인 기능이 없고, 개발자는 앱과 통신하는 서버를 운영하지 않습니다. 광고 SDK와 분석(애널리틱스) 도구도 포함되어 있지 않습니다.

2. 기기 안에만 저장되는 정보

앱 기능을 제공하기 위해 아래 정보가 사용자 기기의 앱 전용 저장소(WebView localStorage)에 저장됩니다. 이 정보는 기기 밖으로 전송되지 않으며 개발자도 볼 수 없습니다.

항목용도
운동 종목, 무게(kg), 반복 횟수, 세트 기록 시각당일 세트 기록과 총 세트·총 볼륨 표시
1RM 계산기 입력값(무게, 횟수)추정 1RM과 강도별 훈련 무게 계산
체중, 활동 수준, 목표권장 칼로리·단백질·탄수화물·지방 계산
휴식 시간, 비프음·진동·자동 시작 설정사용자가 고른 설정 유지

3. 사용하는 기기 기능과 권한

  • 진동(VIBRATE): 휴식 타이머 종료와 세트 기록 시 진동 알림에만 사용합니다.
  • 소리: 앱이 기기에서 직접 합성한 비프음을 재생합니다. 마이크는 사용하지 않습니다.
  • 인터넷(INTERNET): 앱 화면을 표시하는 Android WebView 구성 요소에 필요한 시스템 권한입니다. 앱의 모든 화면과 글꼴은 설치 파일 안에 들어 있으며, 앱은 외부 서버와 통신하지 않습니다.
  • 기기 백업(Google 드라이브 자동 백업)에도 앱 데이터가 포함되지 않도록 설정되어 있습니다.

4. 보관 기간과 삭제 방법

세트 기록은 날짜가 바뀌면 새 기록으로 대체됩니다. 앱 상단의 방패 아이콘 → ‘모든 데이터 삭제’를 누르거나, 기기 설정에서 앱 데이터를 삭제하거나, 앱을 제거하면 저장된 정보가 모두 지워집니다.

5. 제3자 제공 및 국외 이전

수집하는 개인정보가 없으므로 제3자 제공, 처리 위탁, 국외 이전이 없습니다.

6. 아동의 개인정보

앱은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 수집하지 않습니다.

7. 건강 정보 고지

앱이 보여주는 1RM과 칼로리·영양소 수치는 일반 공식(Epley 공식, 체중 기반 추정)으로 계산한 참고값이며 의료 진단이나 치료를 대신하지 않습니다.

8. 방침 변경

이 방침이 바뀌면 이 페이지에 변경 내용과 새 시행일을 게시합니다.
